# Raj Shekhar — Portfolio starter

## Files
- `index.html` — portfolio content and layout
- `style.css` — responsive styling
- `script.js` — mobile navigation
- `README.md` — GitHub profile README

## Preview locally
Open `index.html` in your browser. No build tools are required.

## Publish the portfolio with GitHub Pages
1. Create a repository named `portfolio` (or another name you prefer).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under the build/deployment source, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site; the URL will appear in the Pages settings.

## Set up the GitHub profile README
1. Create a public repository whose name exactly matches your GitHub username: `RajShekhar077`.
2. Add the supplied `README.md` to the repository root and commit it.
3. GitHub will display it on your profile.
